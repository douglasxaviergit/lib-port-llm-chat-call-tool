# AGENTS.md

As regras deste repositório são centralizadas no repo compartilhado **lib-spec**, clonado localmente em `.spec/` (gitignored) e atualizado automaticamente pelo `make all` (alvo `make spec`).

1. `.spec/` não existe? Rode `make spec`.
2. Leia `.spec/AGENTS.md` (ponto de entrada) e siga a tabela de leitura de `.spec/.ai/` — carregue só o relevante à tarefa.
3. Nunca duplique conteúdo normativo aqui — este arquivo é só um ponteiro; a norma mora no lib-spec.
